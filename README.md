# Agnijeet weds Vaidehi

A mobile-first luxury Indian wedding invitation built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Customize

All wedding content lives in `src/data/weddingData.ts`.

Wedding date: **12 December 2026**  
Venue: **The Grand Heritage Resort**

Replace the placeholder couple photos and YouTube ID in `src/data/weddingData.ts`.

Optional music can be enabled with `VITE_WEDDING_MUSIC_URL` in `.env.local`.

## GitHub Pages

The site is configured for deployment from the `gh-pages` branch via GitHub Actions.
